# Учёт аренды опалубки

Статическое веб-приложение: каталог опалубки, склад, сделки аренды и автоматический
расчёт стоимости. Валюта — сомони (`с.`). Данные хранятся в браузере устройства
(`localStorage`), сервер и база не нужны.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение: разметка, стили, логика |
| `manifest.webmanifest` | Описание PWA (имя, иконки, цвета) |
| `sw.js` | Service worker — работа без интернета |
| `icon-192.png`, `icon-512.png` | Иконки для главного экрана |

Все четыре вспомогательных файла должны лежать **рядом** с `index.html`.

## Проверка на телефоне до публикации

В папке проекта:

```powershell
python -m http.server 8080
```

Узнайте IP компьютера (`ipconfig`, строка IPv4) и откройте на телефоне в той же
Wi-Fi-сети `http://<IP>:8080`. Офлайн-режим и установка на главный экран так
работать не будут — для них нужен `https`, то есть публикация.

## Публикация — постоянная ссылка

### Вариант 1. Netlify Drop (быстрее всего, без git)

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите туда **папку целиком** (не отдельный файл).
3. Получите ссылку вида `https://имя.netlify.app`.
4. Зарегистрируйтесь бесплатно, иначе сайт удалится через сутки.
   В настройках сайта можно задать понятное имя.

Обновление: перетащите папку заново в тот же сайт (Deploys → Drag and drop).

### Вариант 2. GitHub Pages

```bash
git init
git add .
git commit -m "Учёт аренды опалубки"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Затем Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
Ссылка появится через минуту: `https://<логин>.github.io/<репозиторий>/`.

### Вариант 3. Cloudflare Pages

Dash → Workers & Pages → Create → Pages → Upload assets, загрузить папку.

## Установка на телефон

Откройте ссылку в браузере:

* **Android / Chrome** — появится плашка «Установить», либо меню ⋮ → «Добавить на главный экран».
* **iPhone / Safari** — Поделиться → «На экран "Домой"». Обязательно Safari, в Chrome на iOS пункта нет.

После установки приложение открывается с иконки без адресной строки и работает
без интернета.

## Резервные копии

Данные лежат только в браузере того устройства, где вы их вводили. Очистка данных
сайта или переустановка браузера их сотрёт.

Меню «Ещё» → **Экспорт в файл** сохраняет всё в один `.json`.
Если копии не было больше двух недель, приложение само напомнит жёлтой плашкой.
**Импорт из файла** восстанавливает данные (полностью заменяя текущие).

## Как считается стоимость

```
сумма = Σ (количество × цена за штуку в день × срок в днях)
```

Цена фиксируется в момент создания сделки: изменение тарифа в каталоге не
пересчитывает уже оформленные аренды. Залог в сумму аренды не входит — он
возвратный и учитывается отдельно.

## Ограничения

* Нельзя выдать больше штук, чем свободно на складе.
* Нельзя уменьшить количество в каталоге ниже того, что сейчас в аренде.
* Нельзя удалить позицию каталога, пока она в аренде.
* Возврат — только целиком. Частичного возврата, продления срока и пени за
  просрочку пока нет.
